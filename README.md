# 📘 SIS - MISSFORD SCHOOL

A complete **Student Information System (SIS)** built with PHP, MySQL, HTML, CSS, and JavaScript. Designed for schools to manage students, staff, grades, payments, admissions, and more.

---

## 📋 Features

### 🔐 Authentication
- Student Login
- Staff Login
- Admin Login
- Password Reset (Forgot Password)
- First Login Password Change

### 👨‍🎓 Student Module
- Dashboard
- Profile (with photo upload)
- Admission Application
- Semester Registration
- Readmission
- Payment (Online Payment)
- Grade Report
- Makeup Exam Request
- Clearance Status
- Transfer Request
- Course Evaluation
- Request Registration (Admin Approval)

### 👨‍🏫 Staff Module
- Dashboard
- Assigned Courses
- Enter Grades
- View Students

### 👑 Admin Module
- Dashboard (with Analytics & Gamification)
- Approve Student Applications
- Approve Registrations
- Add Student
- Add Course
- Add Staff
- Manage Users
- Payments Management
- Reviews Management

### 📊 Dashboard Analytics
- Performance Analytics
- Grade Distribution Chart
- Semester Performance Chart
- Gamification (Points, Level, Badges, Leaderboard)

### 🌍 Multi-Language Support
- English 🇬🇧
- Amharic 🇪🇹
- French 🇫🇷
- Portuguese 🇵🇹

### 🎨 UI Features
- Slideshow Background
- Typing Animation
- Floating Bubbles
- Falling Stars
- Show/Hide Password
- Mobile Responsive
- Favicon & Logo
